# Veterinaria-Database SQL 

Um banco de dados relacional (SQL) feito com MySQL parar uma veterinaria. O sistema foi idealizado para armazenar informações de consultas onde existem as entidades "veterinarios" que interage com a "animais", que por sua vez é uma entidade fraca que depende da entidade "clientes", numa outra entidade "consultas", onde as informações da consulta são armazenadas.
